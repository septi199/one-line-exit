## The resignation

> I quit. The printer is still broken, the Wi-Fi password is still password123, and this is the only thing here that ever worked.

Running `main.ts` writes exactly that line to `/output/entry.txt`. It is deterministic and 127 characters long; the gate allows 1–140.
